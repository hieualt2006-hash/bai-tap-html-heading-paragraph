# Bài Tập: Sử Dụng Thẻ Heading và Paragraph Trong HTML

Bài tập xây dựng trang cá nhân đơn giản sử dụng các thẻ tiêu đề (`<h1>`, `<h2>`) và đoạn văn bản (`<p>`) chuẩn HTML5.

## 📋 Yêu cầu bài tập
- Tạo file `index.html`.
- Thẻ tiêu đề chính `<h1>`: "Chào mừng đến với trang web của tôi".
- Thẻ tiêu đề phụ `<h2>`: "Giới thiệu bản thân".
- Đoạn văn `<p>` thứ nhất: Mô tả sở thích cá nhân.
- Đoạn văn `<p>` thứ hai: Mô tả mục tiêu khi học lập trình.

## 🚀 Cách mở xem
Mở trực tiếp tệp [`index.html`](index.html) bằng trình duyệt web bất kỳ (Chrome, Edge, Firefox,...).
